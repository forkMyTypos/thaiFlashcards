ได้

dâai
falling tone
Auxiliary verb; Verb

to get, receive, obtain, [past tense/completion marker], can, able to

In a sentence

  • ได้เงินแล้ว
    dâai ngoen láew
    I've received the money.
  • ได้จานแล้ว
    dâai jaan láew
    I've got the plate.
  • ได้อันนี้
    dâai an níi
    I've got this one.
  • ได้ชิ้นนี้
    dâai chín níi
    I've got this piece.
  • ได้ใบนี้
    dâai bai níi
    I've got this leaf.
