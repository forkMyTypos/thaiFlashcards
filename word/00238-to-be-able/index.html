สามารถ

sǎa-mâat
rising-falling tone
Adjective; Verb

to be able, can, able, capable

Study it as flashcards

In a sentence

  • สามารถเข้าใจได้ครับ
    sǎa-mâat khâo-jai dâai khráp
    I can understand.\
  • สามารถลองได้ครับ
    sǎa-mâat lɔɔng dâai khráp
    I can try.\
  • สามารถรู้ได้ครับ
    sǎa-mâat rúu dâai khráp
    I can know.\
  • สามารถคิดได้ครับ
    sǎa-mâat khít dâai khráp
    I can think.\
  • สามารถต้องการได้ครับ
    sǎa-mâat dtâwng-gaan dâai khráp
    It is possible to want something.\
