จะ

jà
low tone
Auxiliary verb

[marks future tense or intention] will, shall

Study it as flashcards

Remember it by

jar

In a sentence

  • จะได้ครับ
    jà-dâai khráp
    It will work.\
  • จะไม่ได้ครับ
    jà-mâi-dâai khráp
    It won't work.\
  • วันนี้จะได้ครับ
    wan-níi jà-dâai khráp
    It should work today.\
  • ปีนี้จะได้ครับ
    bpii-níi jà-dâai khráp
    It should work this year.\
  • เดือนนี้จะได้ครับ
    duean-níi jà-dâai khráp
    It should be possible this month.\
  • ตอนนี้จะได้ครับ
    dtɔɔn-níi jà dâai khráp
    It should be possible now.\
  • คืนนี้จะได้ครับ
    khʉʉn-níi jà dâai khráp
    Tonight should work.\
  • เช้านี้จะได้ครับ
    cháo-níi jà dâai khráp
    This morning should work.\
