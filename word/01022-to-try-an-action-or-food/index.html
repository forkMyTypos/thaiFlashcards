ลอง

lɔɔng
mid tone
verb

to try (an action or food), to try

Study it as flashcards

In a sentence

  • ลองอีกครับ
    lɔɔng ìik khráp
    Try again.\
  • ลองแก้วนี้ครับ
    lɔɔng gâeo níi khráp
    Try this glass.\
  • ลองขวดนี้ครับ
    lɔɔng khùat níi khráp
    Try this bottle.\
  • ลองถุงนี้ครับ
    lɔɔng thǔng níi khráp
    Try this bag.
  • ลองหรือครับ
    lɔɔng rue khráp
    Are you trying it?
  • ต้องลองครับ
    dtâwng lɔɔng khráp
    You must try it.\
  • ควรลองครับ
    khuan lɔɔng khráp
    You should try it.\
  • ควรลองอีกครับ
    khuan lɔɔng ìik khráp
    You should try again.\
