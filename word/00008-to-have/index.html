มี

mii
mid tone
Verb

to have, there is, there are

In a sentence

  • มีจาน
    mii jaan
    There is a plate.
  • มีเงิน
    mii ngoen
    There is money.
  • มีตัวนี้
    mii dtua níi
    This one is available.
  • มีอันนี้
    mii an níi
    This one is available.
  • มีชิ้นนี้
    mii chín níi
    This piece is available.
  • มีจานกี่ใบ
    mii jaan gìi bai
    How many plates are there?
  • จานนี้มีเงิน
    jaan níi mii ngoen
    There is money on this plate.
  • มีใบนี้
    mii bai níi
    This leaf is available.
