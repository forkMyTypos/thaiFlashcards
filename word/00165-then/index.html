gâw

Adverb; Conjunction; Particle

In a sentence

  • ถ้าคุณชอบชาก็เอาชาครับ
    thâa khun chɔ̂ɔp chaa gâw ao chaa khráp
    If you like tea, then have tea.
  • ถ้ากาแฟร้อนก็ขอชาเย็นค่ะ
    thâa gaa-fae rɔ́ɔn gâw khɔ̌ɔ chaa yen khâ
    If the coffee is hot, I'll have cold tea.
  • คุณไม่เอาข้าวผมก็ไม่เอาครับ
    khun mâi ao khâao phǒm gâw mâi ao khráp
    If you don't want rice, I won't have it either.
  • ร้านนี้ถูกผมก็ชอบครับ
    ráan níi thùuk phǒm gâw chɔ̂ɔp khráp
    This shop is cheap, so I like it.
  • ถ้าคุณอยากได้ก็ขอได้ค่ะ
    thâa khun yàak dâai gâw khɔ̌ɔ dâai khâ
    If you want it, you can ask for it.
  • ถ้าไม่มีก็ขออีกครับ
    thâa mâi mii gâw khɔ̌ɔ ìik khráp
    If there isn't any, then I'll ask for more.
  • มีน้อยก็ขออีกครับ
    mii nɔ́ɔi gâw khɔ̌ɔ ìik khráp
    There's little, so I'll ask for more.
  • ไม่ได้ก็ขออีกครับ
    mâi dâai gâw khɔ̌ɔ ìik khráp
    If that's not possible, then I'll ask for more.
