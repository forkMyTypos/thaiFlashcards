ช่วย

chûay
falling tone
Auxiliary verb; Verb

to help, assist, please [used before a request]

Study it as flashcards

In a sentence

  • ช่วยอะไรครับ
    chûay à-rai khráp
    How can I help?\
  • ช่วยได้ครับ
    chûay dâai khráp
    I can help.\
  • ช่วยทำได้ครับ
    chûay tham dâai khráp
    I can help do it.\
  • ช่วยดูได้ครับ
    chûay duu dâai khráp
    I can help look.\
  • ช่วยเขียนได้ครับ
    chûay khǐian dâai khráp
    I can help write it.
  • ช่วยดูด้วยครับ
    chûay duu dûay khráp
    Please help look too.
  • ช่วยพูดด้วยครับ
    chûay phûut dûay khráp
    Please speak too.\
  • ช่วยถามด้วยครับ
    chûay thǎam dûay khráp
    Please ask too.
