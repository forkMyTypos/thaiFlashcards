นี้

níi
high tone
Adjective; Pronoun

this, these

Study it as flashcards

Remember it by

knee

A person proudly holds one specific object directly toward the viewer to indicate this one.

In a sentence

  • กล้วยลูกนี้หวานมาก
    glûai lûuk níi wǎan mâak
    This banana is very sweet.
  • มะม่วงลูกนี้อร่อยมาก
    má-mûang lûuk níi à-rɔ̀i mâak
    This mango is very delicious.
  • มะเขือเทศลูกนี้แดงมาก
    má-khʉ̌ʉa-thêet lûuk níi daeng mâak
    This tomato is very red.
  • แกงนี้หวานไปนิด
    gaeng níi wǎan bpai nít
    This curry is a little too sweet.
  • ซุปนี้ร้อนเกินไป
    súp níi rɔ́ɔn gəən bpai
    This soup is too hot.
  • ฉันชอบชานี้ค่ะ
    chǎn châawp chaa níi khâ
    I like this tea.
  • คุณอยากกินไข่นี้ไหมครับ
    khun yàak gin khài níi mǎi khráp
    Do you want to eat this egg?
  • กาแฟนี้ร้อนมากค่ะ
    gaa-fɛɛ níi rɔ́ɔn mâak khâ
    This coffee is very hot.
