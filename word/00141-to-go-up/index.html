ขึ้น

khûen
falling tone
Preposition; Verb

to go up, rise, ascend, increase, get on [vehicle], up, depends on

Study it as flashcards

In a sentence

  • ขึ้นได้ครับ
    khûen dâai khráp
    You can go up.
  • ขึ้นแล้วครับ
    khûen láew khráp
    I've gone up.
  • ขึ้นก่อนครับ
    khûen gɔ̀ɔn khráp
    Go up first, please.
  • จะขึ้นหรือครับ
    jà khûen rʉ̌ʉ khráp
    Are you going up?
  • ขึ้นอีกได้ครับ
    khûen ìik dâai khráp
    You can go up again.
  • ขึ้นเร็ว
    khûen reo
    Go up quickly.
  • วันนี้จะขึ้น
    wan-níi jà khûen
    Will go up today.
  • วันนี้ต้องขึ้น
    wan-níi dtâwng khûen
    Must go up today.
