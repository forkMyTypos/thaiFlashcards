Study it as flashcards

In a sentence

  • ถ้าเผ็ดขอน้ำเย็นค่ะ
    thâa phèt khǎaw náam yen khâ
    If it's spicy, I'll have cold water.
  • ถ้ากินข้าวขอน้ำครับ
    thâa gin khâao khǎaw náam khráp
    If I'm eating rice, I'd like water.
  • ถ้ามีไข่ขออีก2ฟองครับ
    thâa mii khài khǎaw ìik sǎawng faawng khráp
    If you have eggs, I'd like two more.
  • ถ้าถูกฉันเอา2ถุงค่ะ
    thâa thùuk chǎn ao sǎawng tǔng khâ
    If it's cheap, I'll take two bags.
  • ถ้าคุณอยากได้ก็เอาครับ
    thâa khun yàak dâai gâaw ao khráp
    If you want it, take it.
  • ถ้าไม่มีก็ไม่ไปครับ
    thâa mâi mii gâw mâi bpai khráp
    If there isn't any, I won't go.
  • ถ้าได้ ก็ขออีกครับ
    thâa dâai gâw khɔ̌ɔ ìik khráp
    If it's possible, I'd like more.
  • ถ้ามีน้อย ก็ขออีกครับ
    thâa mii nɔ́ɔi gâw khɔ̌ɔ ìik khráp
    If there is only a little, I'd like more.
