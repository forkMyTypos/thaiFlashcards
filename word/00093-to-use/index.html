ใช้

chái
high tone
Verb

to use, employ, spend [time/money]

Study it as flashcards

Remember it by

shy

In a sentence

  • ใช้อะไรครับ
    chái à-rai khráp
    What are you using?\
  • ใช้ได้ครับ
    chái dâai khráp
    You can use it.\
  • ใช้ก่อนครับ
    chái gɔ̀ɔn khráp
    Use it first, please.\
  • ใช้กับโต๊ะได้ครับ
    chái gàp dtó dâai khráp
    You can use it with the table.\
  • ต้องใช้อีกครับ
    dtɔ̂ng chái ìik khráp
    I need to use it again.
