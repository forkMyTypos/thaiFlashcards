How to learn Thai with this course

What this course is

A free Thai vocabulary course with 462 lessons, 4,778 words and 2,430 example sentences. Words are shown in Thai script with romanization and an English meaning, many have audio, and each lesson can be studied as flashcards or a quiz. No sign-up.

How a lesson works

Each lesson is a short set of related words. You can work through it three ways, using the mode buttons on the lesson page:

  • Read it — the word in Thai script, its romanization and meaning, a memory aid where there is one, and example sentences.
  • Flashcards — the answer stays hidden until you ask for it, so you can test yourself.
  • Quiz — pick the right word from a few choices.

Where to start

Start with Questions and connections, then follow the lessons in order, or jump to a topic you need.

Questions

Is it free?

Yes. There is no sign-up and nothing to pay.

Does it show how to say the words?

Words are shown in Thai script with a romanization, and many have a recording you can play at normal speed or slowly.

Do I need to learn the script first?

No. The romanization is shown beside the words, so you can start without reading the script and pick it up as you go.

Where is my progress kept?

In your own browser: what you have marked as known is saved on your device, so there is no account to create.
